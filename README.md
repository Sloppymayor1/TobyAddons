# TobyAddons

Custom addons for World of Warcraft Forever.

| Addon | Install folder | Notes |
| --- | --- | --- |
| ForeverFarmRoute | `ForeverFarmRoute` | Farming routes, gathering combos, and node memory. Use `/farm`. |
| Auctionator Shuffle | `AuctionatorShuffle` | Crafting and shuffle profit estimates. Install Auctionator separately and use `/shuffle`. |

Copy the addon folder you want to `World of Warcraft\_forever_\Interface\AddOns`.
